# 規制ワークロード対応チェックリスト

## 目的

規制産業（公共セクター、ヘルスケア、金融サービス、教育）での AI メタデータカタログ本番デプロイのためのチェックリスト。

## データレジデンシー

| 要件 | 設計 | エビデンス |
|------|------|----------|
| 生ファイルが指定リージョンに残る | FSx for ONTAP を単一リージョンに配置 | FSx ファイルシステム ARN |
| メタデータが指定リージョンに残る | S3 Tables を同じリージョンに配置 | テーブルバケット ARN |
| AI 処理が同じリージョン | Bedrock エンドポイントが同じリージョン | API エンドポイント URL |
| 越境データ転送なし | 全サービスが同一リージョン | VPC フローログ |

## 暗号化

| レイヤー | 方式 | 鍵管理 |
|---------|------|--------|
| 生ファイル保存時 | FSx for ONTAP 暗号化 | AWS KMS または FSx マネージド |
| メタデータ保存時 | S3 Tables SSE-S3 | AWS マネージド |
| 転送時 | TLS 1.2+（全 API コール） | AWS デフォルト |
| OpenSearch 保存時 | AWS マネージド暗号化 | Serverless デフォルト |

## アクセス境界

### 生データアクセス境界

| コンポーネント | アクセス方法 | 認可 |
|-------------|------------|------|
| 本番アプリ | NFS/SMB | ONTAP ファイル権限 |
| AI エンリッチメント | S3 Access Point | IAM + AP ポリシー + ONTAP ID |
| アナリストクエリ | 直接ファイルアクセスなし | Athena/Snowflake 経由のメタデータのみ |

### メタデータアクセス境界

| コンポーネント | アクセス方法 | 認可 |
|-------------|------------|------|
| Athena クエリ | Glue カタログ経由 SQL | Lake Formation グラント |
| Snowflake クエリ | VENDED_CREDENTIALS | Lake Formation + IAM |
| OpenSearch 検索 | kNN API | IAM + VPC エンドポイント |
| 管理操作 | PyIceberg/CLI | IAM + Lake Formation 管理者 |

## AI 処理データフロー

```
FSx for ONTAP 上のファイル
  → S3 Access Point 経由で読み取り（メモリ上にファイル内容）
  → Bedrock API に送信（TLS、プロバイダーは保存しない）
  → 分類 + エンベディングを返却
  → S3 Tables に書き込み（メタデータのみ）
  → オプションで OpenSearch にインデックス
  → 元ファイルはコピーも移動もされない
```

[AWS Bedrock データ保護](https://docs.aws.amazon.com/bedrock/latest/userguide/data-protection.html) に基づき：
- モデルプロバイダーは顧客のプロンプトや完了結果にアクセスできない
- 入出力はモデルトレーニングに使用されない
- データは API エンドポイントと同じリージョンで処理される

## PII 検出スコープと制限

| 言語 | エンジン | カバレッジ | 既知のギャップ |
|------|---------|----------|-------------|
| 英語 | Amazon Comprehend | NAME, EMAIL, PHONE, ADDRESS, SSN, CREDIT_CARD | 文脈依存の PII は見逃す可能性 |
| 日本語 | Bedrock Claude | 氏名, メール, 電話, 住所, マイナンバー | 新しい PII タイプはプロンプト更新が必要 |
| その他の言語 | 未対応 | — | 追加エンジン統合が必要 |

**重要**: PII 検出は補助的であり網羅的ではない。偽陰性の可能性あり。規制準拠にはヒューマンレビューが必須。

## 監査とエビデンス

| 監査タイプ | ソース | 保持期間 | 分析 |
|----------|--------|---------|------|
| メタデータクエリ監査 | CloudTrail | 90日（デフォルト）/ Trail で延長 | CloudTrail Lake または Athena |
| ファイルアクセス監査 | ONTAP 監査ログ | 設定可能 | SVM 監査ポリシー |
| AI 呼び出し監査 | CloudTrail (Bedrock) | 90日（デフォルト） | CloudTrail Lake |
| ガバナンス変更 | CloudTrail (Lake Formation) | 90日（デフォルト） | CloudTrail Lake |

## 削除と保持

| データタイプ | 保持オーナー | 削除メカニズム | エビデンス |
|-----------|------------|-------------|----------|
| 生ファイル | ストレージ管理者 | FSx ファイル削除 | ONTAP 監査ログ |
| メタデータレコード | カタログ管理者 | Iceberg append (is_deleted=true) | Athena クエリ |
| Iceberg スナップショット | S3 Tables サービス | 自動有効期限（設定可能） | S3 Tables 設定 |
| OpenSearch インデックス | プラットフォーム管理者 | インデックス削除 | API コールログ |
| Snowflake 同期 | Snowflake 管理者 | Table DROP / Time Travel 期限切れ | Snowflake クエリ履歴 |

> **警告**: Iceberg タイムトラベルはスナップショットが期限切れになるまで削除済みメタデータを公開する可能性がある。スナップショット有効期限を削除 SLA に合わせること。

## 法務・コンプライアンスサインオフ

| 項目 | オーナー | ステータス |
|------|---------|----------|
| データ処理契約 | 法務 | 本番前に必須 |
| AI 利用承認 | コンプライアンス | Bedrock 利用に必須 |
| PII 取扱承認 | DPO / プライバシー | PII 検出に必須 |
| 監査保持ポリシー | セキュリティ + 法務 | 保持期間を定義 |
| インシデント対応計画 | セキュリティ | 侵害通知 SLA を定義 |
| サードパーティアクセスレビュー | セキュリティ | Snowflake/Databricks データフローレビュー |

## 本番承認ゲート

規制環境での本番デプロイ前に、以下のゲートを順番に完了すること：

1. **データオーナー承認** — スコープ内データ、分類レベル、許容される AI 処理を確認
2. **セキュリティアーキテクチャレビュー** — IAM、ネットワーク、暗号化、アクセス境界を検証
3. **法務/コンプライアンスレビュー** — データ処理契約、AI 利用条件、越境評価
4. **AI 評価サインオフ** — 分類精度、PII 検出偽陰性率、ヒューマンレビュー受容率が定義閾値を満たす
5. **運用レディネスレビュー** — ランブック、アラート、DR 手順、コストモデルが検証済み
6. **削除/保持 SLA 承認** — スナップショット有効期限、メタデータ保持、監査エビデンス保持がポリシーに整合

## エビデンスマッピング

監査・コンプライアンスレポートのため、エビデンスを以下のカテゴリにマッピング：

| エビデンスカテゴリ | ソース | 保管場所 |
|----------------|--------|---------|
| アクセス制御 | CloudTrail + Lake Formation ログ | CloudTrail Lake / S3 Trail バケット |
| AI 評価 | ラベル付き検証セット結果 | `verification-evidence/ai-evaluation/` |
| PII 編集 | 編集前後のサンプル | `verification-evidence/pii-redaction/` |
| 削除 | スナップショット有効期限ログ + 生ファイル削除監査 | ONTAP 監査ログ + S3 Tables 設定 |
| クロスプラットフォームアクセス | Athena / Snowflake / EMR スクリーンショット + クエリログ | `snowflake/screenshots/`, CloudTrail |
| ガバナンス変更 | Lake Formation grant/revoke ログ | CloudTrail |
| パフォーマンスベースライン | デモ実行ログ、レイテンシ計測 | `verification-evidence/2026-05-31/` |
