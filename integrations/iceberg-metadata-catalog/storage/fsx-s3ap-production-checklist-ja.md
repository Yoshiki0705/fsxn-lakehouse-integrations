# FSx for ONTAP S3 Access Point — 本番チェックリスト

## 目的

メタデータカタログアーキテクチャで使用する FSx for ONTAP S3 Access Point の本番前検証チェックリスト。

## ID とアクセス

| 項目 | 説明 | ステータス |
|------|------|----------|
| S3 AP ID 文書化 | 各 AP の OntapFileSystemIdentity（UNIX UID/GID または Windows ユーザー） | |
| ID スコープ最小化 | AP ID がターゲットボリューム/パスへの読み取りアクセスのみ | |
| IAM プリンシパルスコープ | 認可された Lambda/ECS ロールのみが AP を使用可能 | |
| S3 AP リソースポリシー | 認可プリンシパルの明示的許可リスト | |
| ONTAP ファイルシステム権限マッピング | UNIX モードビットまたは NTFS ACL が AP ID に整合 | |
| SVM / ボリューム / ジャンクションパススコープ | AP が正しいボリュームにアタッチ、必要以上に広くない | |
| AP エイリアス文書化 | SDK アクセス用の外部エイリアス | |

## パフォーマンスとキャパシティ

| 項目 | 説明 | ステータス |
|------|------|----------|
| キャパシティプール読み取り影響 | AI エンリッチメントバックフィル中のコールドファイル読み取りを理解 | |
| S3 リクエスト並行数 | Lambda/ECS 並行数 vs FSx プロビジョニングスループット | |
| 本番 NFS/SMB レイテンシ影響 | S3 AP 読み取りが本番ワークロードを劣化させない | |
| スロットリング/リトライ動作 | 503/スロットル応答に対するリトライ戦略を文書化 | |
| ListObjectsV2 ページネーション | ターゲットファイル数（100K+ ファイル）でテスト済み | |
| 大容量ファイル処理 | 100MB 超のファイルは別処理パス（ECS Fargate） | |
| バックフィルスケジューリング | 初期スキャンはオフアワーで本番影響を最小化 | |

## データ整合性

| 項目 | 説明 | ステータス |
|------|------|----------|
| スキャン結果チェックサム | 各実行後にスキャン完全性を検証 | |
| scan_run_id 追跡 | 各スキャン実行に一意の ID（照合用） | |
| 期待 vs カタログ化ファイル数 | 照合レポートがデルタを表示 | |
| 失敗ファイルリトライリスト | 読み取り失敗用の DLQ またはエラーテーブル | |
| 名前空間スキャン照合 | 定期的なフルスキャン vs インクリメンタルデルタ | |
| ファイルリネーム/削除検出 | インクリメンタルスキャンが削除/リネームを検出 | |
| 古いメタデータクリーンアップ | 削除ファイルがカタログで is_deleted マーク | |

## モニタリング

| 項目 | 説明 | ステータス |
|------|------|----------|
| CloudWatch メトリクスダッシュボード | FSx スループット、IOPS、レイテンシ、キャパシティプール読み取り | |
| S3 AP リクエストメトリクス | AP あたりのリクエスト数、レイテンシ、エラー | |
| Lambda/ECS エラー率 | エンリッチメントパイプラインエラー率 < 5% 閾値 | |
| DLQ 深度アラーム | 失敗メッセージが閾値超過で通知 | |
| エンリッチメントバックログメトリック | enrichment_status = 'pending' のファイル数 | |
| コスト配分タグ | AP 別、ボリューム別のコスト追跡 | |

## セキュリティ

| 項目 | 説明 | ステータス |
|------|------|----------|
| S3 用 VPC エンドポイント | S3 トラフィックが VPC 内にとどまる（インターネットなし） | |
| Bedrock 用 VPC エンドポイント | AI API コールが VPC 内にとどまる | |
| IAM 最小権限 | 各ロールが最小限必要な権限のみ | |
| S3 AP ポリシーデフォルト拒否 | 認可された操作のみ明示的許可 | |
| 監査証跡 | CloudTrail が全 S3 AP API コールをログ | |
| コードにクレデンシャルなし | 全シークレットが Secrets Manager または SSM Parameter Store | |
