## 業界固有

### ヘルスケア (HIPAA)
- [ ] AWS との BAA 締結済み
- [ ] PoC 環境に実 PHI なし
- [ ] 匿名化パイプライン検証済み（PoC 後に実データ使用する場合）
- [ ] 最小必要原則適用（必要なもののみアクセス）

### 金融サービス (PCI DSS / SOX)
- [ ] 職務分離（管理者 ≠ アナリスト）
- [ ] 変更管理プロセス文書化
- [ ] 監査証跡保持 ≥7年
- [ ] DR/BCP 計画に FSx for ONTAP S3 AP パスを含む

### 公共セクター
- [ ] データ主権確認（単一リージョン）
- [ ] FedRAMP/ISO 認証要件を AWS サービスが満たす
- [ ] 分類レビューなしにデータエクスポートなし
