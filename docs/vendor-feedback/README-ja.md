# ベンダーフィードバック

本リポジトリの検証で得られた所見を、ベンダーごとに独立して読めるようまとめたものです。

## これらのドキュメントの位置づけ

各ページは、何を計測したか、その計測が製品上に構築する人にとって何を意味するか、
何があれば解消するかを記述しています。全項目が [`verification-pack/`](../../verification-pack/)
配下のエビデンス記録を参照するか、観測されたレイヤーを明示しています。

これはエンジニアリング上の観測であり、苦情でも順位付けでもありません。差分がある場合は
代替手段側のトレードオフも併記します。製品が正しく振る舞っており本リポジトリの以前の
記述が誤っていた場合は、同じページに訂正を記録します。

## これらのページのルール

| ルール | 理由 |
|---|---|
| サポートケース番号、担当者名、内部チケット ID を含めない | 公開ドキュメントであるため |
| 記録があるものはエラー文字列を原文のまま記載 | 正確な文字列は検索・再現が可能。言い換えでは不可能 |
| 推論は推論として明示 | 1件（Hudi）は実測ではなく推論。その旨を明記している |
| 取り下げた主張は削除せず残す | 再現しなかった主張も結果である。黙って削除すると記録の信頼性が下がる |
| 代替手段はそれ自身のトレードオフとともに記述 | ある製品の差分は別の製品を推す論拠にはならない |
