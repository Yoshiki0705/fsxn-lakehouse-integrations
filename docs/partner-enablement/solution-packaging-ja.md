# パートナーソリューションパッケージング

## オファー概要

**ワンライナー**: 生ファイルを S3 にバルクコピーすることなく、エンタープライズ NAS データを検索可能・ガバナンス対応・AI-ready にする。

| 項目 | 内容 |
|------|------|
| オファー名 | エンタープライズ NAS 向け AI メタデータカタログ |
| ターゲット顧客 | 製造業、ヘルスケア、金融サービス、公共セクター、エンジニアリング組織 |
| 主な課題 | 非構造化データの発見、メタデータガバナンス、生データコピーなしの AI 活用 |
| 差別化ポイント | 既存 NAS ストレージ（FSx for ONTAP）上でのゼロコピーメタデータカタログ; 複数エンジン（Athena, Snowflake, EMR, Databricks）からのガバナンス付きアクセス |

## デリバリーモデル

| モデル | 期間 | スコープ | 成果物 |
|--------|------|---------|--------|
| アセスメント | 2週間 | データランドスケープ調査、FSx 設定、ガバナンス要件 | アーキテクチャ推奨 + コスト見積もり |
| PoC | 4週間 | 顧客 FSx 環境でメタデータカタログをデプロイ、サンプルデータで検証 | 動作デモ + 計測 KPI |
| 本番パイロット | 8-12週間 | 本番ボリューム対応、AI エンリッチメント、ガバナンス統合、モニタリング | 本番グレードデプロイメント |
| マネージドサービス | 継続 | パートナー運用のカタログ（SLA付き） | メタデータ鮮度 + 検索可用性 |

## 業界別ターゲットユースケース

| 業界 | 主要ユースケース | 副次ユースケース |
|------|-----------------|-----------------|
| 製造業 | CAD/図面発見、品質検査文書、センサーログカタログ | AI 支援の欠陥分類 |

| エンジニアリング | 設計文書バージョニングカタログ、シミュレーション出力発見 | チーム横断コラボレーションメタデータ |

## AWS Marketplace 検討

本ソリューションは AWS Marketplace オファーとしてパッケージ可能：
- **マルチプロダクトソリューション**: FSx for ONTAP + S3 Tables + Bedrock + OpenSearch を組み合わせ
- **コンサルティングオファー**: アセスメント → PoC → 本番パイロット パス
- **AMI/コンテナ**: 事前設定済み Lambda + デモスクリプトで迅速デプロイ

## パートナー共同販売アライメント

| AWS プログラム | アライメント |
|---------------|-------------|
| ISV Accelerate | Marketplace リスティング + AWS フィールドとの共同販売 |
| Migration Competency | データ移動なしの NAS モダナイゼーション |
| Data & Analytics Competency | メタデータガバナンス + マルチエンジンアクセス |
| GenAI Competency | Bedrock Vision + Embeddings + RAG レディネス |

## マルチテナント設計考慮事項

パートナーマネージドデプロイメントで複数顧客にサービス提供する場合：

- テナントオンボーディングワークフロー（SVM/ボリューム/AP の自動作成）
- テナントオフボーディングとエビデンス削除（監査証跡は保持）
- テナント別コスト配分（S3 Tables, Lambda, Bedrock 呼び出しにタグ付与）
- テナント別 OpenSearch インデックス戦略（共有 vs 分離）
- テナント別 Lake Formation / Snowflake / Databricks ポリシーマッピング
- テナント分離検証（ペネトレーションテストエビデンス）
