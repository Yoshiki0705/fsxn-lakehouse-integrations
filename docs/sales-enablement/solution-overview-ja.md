# FSx for ONTAP × AI メタデータカタログ ソリューション概要

> NetApp Japan フィールドセールス向け 1-Pager

---

## 課題

- **NAS データはダークデータ化している**: ファイルサーバー上の非構造化データは検索・分析不能。何がどこにあるか誰も把握できない
- **データコピーはコストと時間の浪費**: 分析のために S3 へコピーすると、ストレージ費用が 2 倍以上。100TB で月額 $2,280+ 増
- **手動分類はスケールしない**: 人手によるファイル分類・タグ付けは非現実的。1 日数千ファイルの変更に追従不可能

## 競合優位性

| 比較対象 | 課題 | NetApp の優位性 |
|----------|------|-----------------|
| Pure Storage FlashBlade | オブジェクトストアへのコピー必須、FPolicy 相当なし | **ゼロコピー + FPolicy イベント駆動** |
| Dell PowerScale/ECS | Isilon→ECS データ移行必須、AWS ネイティブ統合なし | **S3 AP による AWS ネイティブ統合** |
| AWS S3 + Glue のみ | NAS からの全量データ移行が前提 | **既存 NAS をそのまま活用** |
| Databricks Unity Catalog | S3 コピー必須、NFS ゼロコピー不可 | **ONTAP マルチプロトコル** |
