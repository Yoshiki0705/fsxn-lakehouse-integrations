# 3 分エレベーターピッチ: FSx for ONTAP AI メタデータカタログ

> 想定シーン別スクリプト（各 3 分）

---

## シナリオ 1: フィールドエンジニア → お客様

### オープニングフック（30 秒）

「御社のファイルサーバーに何テラバイトのデータがありますか？ 多くのお客様は "何がどこにあるか分からない" とおっしゃいます。実は、そのデータを動かさずに AI で自動分類し、検索可能にする方法があります。」

### 課題提起（45 秒）

「ファイルサーバー上の非構造化データは、コピーしないと分析できないのが常識でした。しかしコピーすれば、ストレージコストは倍増し、データ整合性の管理も複雑になります。手動でタグ付けしようにも、日々数千ファイルが変更される環境では追いつきません。」

### ソリューション（60 秒）

「このソリューションは、FSx for ONTAP の S3 Access Point を使い、AI パイプラインを NAS に直接接続します — データコピー不要です。

仕組みはシンプルです：
1. ファイルが作成・変更されると FPolicy が検知
2. Lambda が S3 Access Point 経由でファイルにアクセス（読み取り専用、ゼロコピーストレージ）
3. Amazon Bedrock がファイルを自動分類し、メタデータを生成
4. 結果は Apache Iceberg テーブルに格納され、Athena や OpenSearch で即座に検索可能

**ファイル原本は FSx for ONTAP 上のまま。動くのはメタデータだけです。**

補足として：S3 AP はこのパイプラインでは読み取り専用で使用（書き込みもサポート）（分析からの書き戻し不可）で、AI 分類精度はファイルタイプや言語により変動します。実データでの PoC 検証を推奨しています。」

### 実証ポイント（30 秒）

「PoC での実績：ファイル配置から検索可能になるまで **42 秒**。1 ファイルあたりのコスト **$0.07**（100KB–1MB のドキュメント想定）。10 万ファイル環境で月額 **$114**。保守的 ROI 見積もりで 2 週間以内に投資回収。

これは PoC 結果です — 本番パフォーマンスはファイル構成に依存します。」

### クロージング（15 秒）

「30 分のハンズオンデモをご用意しています。CloudFormation で全スタックをデプロイします。御社のファイルに近い環境で動作を見ていただくのはいかがでしょうか？」

## シナリオ 2: フィールドエンジニア → SI パートナー

### オープニングフック（30 秒）

「貴社のお客様の中に、NAS 上のファイル管理・検索で悩んでいる企業はありませんか？ CloudFormation テンプレート、デモスクリプト、20 業種テンプレート付きのソリューションパッケージを用意しました。」

### ビジネス機会（45 秒）

「多くの企業が NAS データの活用を望んでいますが、データレイクへのフル移行は正当化できません。このソリューションはデータ移動なしで即座に AI 検索を提供 — 貴社にとっては：
- **初期構築案件**（1〜2 週間の PoC → 本番構築）
- **月次運用収益**（パイプライン監視、精度チューニング、ダッシュボード保守）
- **横展開のしやすさ**（20 業種テンプレートで別顧客へ迅速展開）」

### ソリューション概要（60 秒）

「技術的には CloudFormation でインフラ構築を自動化済みです：

- Phase 1: インフラ（1〜2 日）— FSx for ONTAP + S3 Tables + Lambda
- Phase 2: AI パイプライン（2〜3 日）— Bedrock 連携 + FPolicy 設定
- Phase 3: 検索 UI（1〜2 日）— Athena + OpenSearch ダッシュボード

合計 **5〜7 営業日** で本番稼働可能。

お客様への説明時のポイント：S3 AP は読み取り専用、FPolicy は ~1–5ms のレイテンシ追加、Bedrock 精度は PoC で検証すべき。率直に伝えて問題ない内容です。」

### 実証ポイント（30 秒）

「数字：パイプライン実行 42 秒、$0.07/ファイル。50 人部門が検索時間を 1 人 10 分/日削減する保守的 ROI：月額約 30 万円の生産性効果 — 対してコスト $114/月。」

### クロージング（15 秒）

「パートナー SE 向け 30 分ハンズオンを実施できます。翌日からお客様提案に使えます。スケジュールを決めましょう。」

## シナリオ 3: フィールドエンジニア → ディストリビューター SE

### オープニングフック（30 秒）

「FSx for ONTAP のお客様を担当する SE 向けに — 既存ファイルストレージ上にデータ分析をアップセルする差別化ストーリーをお持ちしました。」

### 市場機会（45 秒）

「FSx for ONTAP ユーザーの多くは "ファイルサーバー移行完了" で止まっています。次のステップとしてデータ活用を提案すれば、ストレージ以外の AWS サービス売上にもつながります。

市場コンテキスト：
- 非構造化データは年率 60% 以上増加
- 80% 以上がダークデータ（未活用）
- AI によるデータ分類の需要は加速中」

### ソリューション（60 秒）

「お客様への提案はシンプルです：

"FSx for ONTAP のファイルを、コピーせずに AI で検索可能にしませんか？"

技術的な裏付け：
- S3 Access Point でゼロコピーストレージアクセス（読み取り専用）
- Amazon Bedrock で AI 自動分類（日本語対応）
- Apache Iceberg (S3 Tables) でメタデータ管理
- Athena/OpenSearch で検索・分析

**お客様に必要なのは既存の FSx for ONTAP 環境だけです。**

制約については率直に：読み取り専用アクセス、FPolicy レイテンシ（~1–5ms）、分類精度は PoC 検証が必要。」

### 実証ポイント（30 秒）

「デモ: 42 秒でエンドツーエンド。コスト: $0.07/ファイル、月額 $114（10 万ファイル）。保守的効果: ユーザー 1 人あたり検索時間 10 分/日削減。50 人で月額約 $2,500 の保守的生産性効果。」

### クロージング（15 秒）

「30 分の SE 勉強会を実施できます。実機デモ付き — 翌日からパートナー紹介に使えます。」
