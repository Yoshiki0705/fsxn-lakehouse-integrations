# 3 分エレベーターピッチ: FSx for ONTAP AI メタデータカタログ

> 想定シーン別スクリプト（各 3 分）

---

## シナリオ 1: NetApp セールス → お客様

### オープニングフック（30 秒）

「御社のファイルサーバーに何テラバイトのデータがありますか？ 多くのお客様は "何がどこにあるか分からない" とおっしゃいます。実は、そのデータを動かさずに AI で自動分類し、検索可能にする方法があります。」

### 課題提起（45 秒）

「ファイルサーバー上の非構造化データは、コピーしないと分析できないのが常識でした。しかしコピーすれば、ストレージコストは倍増し、データ整合性の管理も複雑になります。手動でタグ付けしようにも、日々数千ファイルが変更される環境では追いつきません。」

### ソリューション（60 秒）

「私たちのソリューションは、FSx for ONTAP の S3 Access Point を使い、ファイルを一切コピーせずに AI パイプラインに接続します。

仕組みはシンプルです：
1. ファイルが作成・変更されると FPolicy が検知
2. Lambda が S3 Access Point 経由でファイルにアクセス
3. Amazon Bedrock がファイルを自動分類し、メタデータを生成
4. 結果は Apache Iceberg テーブルに格納され、Athena や OpenSearch で即座に検索可能

**ファイル原本は FSx 上のまま。動くのはメタデータだけです。**」

### 実証ポイント（30 秒）

「実際のデモでは、ファイル配置から検索可能になるまで **42 秒**。1 ファイルあたりのコストは **$0.07**。10 万ファイル環境でも月額わずか **$114** で運用できます。ストレージコスト削減は 95% — フルコピーと比較してです。」

### 差別化（15 秒）

「競合ソリューションではデータコピーが必須ですが、NetApp は ONTAP の S3 Access Point とマルチプロトコル対応で、唯一のゼロコピーアーキテクチャを実現しています。」

### クロージング（15 秒）

「30 分のハンズオンデモをご用意しています。CloudFormation 一発デプロイで、御社の環境でもすぐに体験できます。日程を調整させてください。」

## シナリオ 2: NetApp セールス → SI パートナー

### オープニングフック（30 秒）

「貴社のお客様の中に、ファイルサーバーのデータ活用で悩んでいる企業はありませんか？ 私たちは SI パートナー様向けに、すぐに提案・構築できるソリューションパッケージを用意しました。」

### 課題とビジネス機会（45 秒）

「多くの企業が NAS 上の非構造化データを活用したいと考えていますが、データレイクへの移行プロジェクトは期間もコストも読めません。そこで、データを移動せずに AI で分類・検索可能にするソリューションを開発しました。

貴社にとっては：
- **初期構築案件**（1〜2 週間の PoC → 本番構築）
- **月次運用収益**（FPolicy 監視、Bedrock チューニング、ダッシュボード保守）
- **横展開のしやすさ**（20 業種テンプレートで即座に別顧客へ展開）」

### ソリューション概要（60 秒）

「技術的には CloudFormation テンプレートで環境構築は自動化済みです。

構築フェーズ：
- Phase 1: インフラ（1〜2 日）— FSx for ONTAP + S3 Tables + Lambda
- Phase 2: AI パイプライン（2〜3 日）— Bedrock 連携 + FPolicy 設定
- Phase 3: BI/検索 UI（1〜2 日）— Athena + OpenSearch ダッシュボード

合計 **5〜7 営業日** で本番稼働可能です。」

### 実証ポイント（30 秒）

「パイプライン実行は 42 秒、1 ファイル $0.07。お客様への ROI 説明も明快です。手作業でのファイル検索時間を 1 人あたり 30 分/日削減できれば、50 人の部門で月額 75 万円相当の工数削減になります。」

### 差別化と提供物（15 秒）

「パートナー様には CloudFormation テンプレート、デモスクリプト、20 業種テンプレート、インフラ見積もりテンプレートをすべてお渡しします。自社ブランドでの提案が可能です。」

### クロージング（15 秒）

「まずはパートナー SE 向けのハンズオンを実施しませんか？ 30 分で一通り体験でき、翌日からお客様提案に使えます。」

## シナリオ 3: NetApp → ディストリビューター SE

### オープニングフック（30 秒）

「ディストリビューター様の SE 向けに、差別化提案のネタをお持ちしました。FSx for ONTAP の既存ユーザーに対して、追加の付加価値を提案できるソリューションです。」

### 課題と市場機会（45 秒）

「FSx for ONTAP を使っているお客様の多くは、ファイルサーバー移行で止まっています。次のステップとして "データ活用" を提案できれば、ストレージ以外の AWS サービス売上にもつながります。

市場規模：
- 非構造化データは年率 60% 増加
- 80% 以上のデータがダークデータ（未活用）
- AI によるデータ分類の需要は急増中」

### ソリューション概要（60 秒）

「提案のポイントはシンプルです：

"御社の FSx for ONTAP のファイルを、コピーせずに AI で自動分類し、いつでも検索できるようにしませんか？"

技術的な裏付け：
- S3 Access Point でゼロコピーアクセス
- Amazon Bedrock で AI 自動分類（日本語対応）
- Apache Iceberg (S3 Tables) でメタデータ管理
- Athena/OpenSearch で検索・分析

**お客様に必要なのは既存の FSx for ONTAP 環境だけです。**」

### 実証ポイント（30 秒）

「数字で語れます：
- デモ: 42 秒でエンドツーエンド完了
- コスト: $0.07/ファイル、月額 $114（10 万ファイル）
- 削減: ストレージコスト 95% カット（フルコピー比）
- 効果: 検索時間 30 分/日/人の削減」

### チャネル向けメリット（15 秒）

「FSx for ONTAP の既存案件のアップセル、SI パートナーとの協業案件創出、AWS Marketplace 経由の取引機会拡大に直結します。」

### クロージング（15 秒）

「SE 勉強会を 30 分で実施できます。実機デモ付きで、翌日からパートナー様への紹介が可能です。スケジュールを決めましょう。」
