# コスト見積もり: FSx for ONTAP AI メタデータカタログ

> キャパシティプランニングのためのコンポーネント別コスト内訳とスケーリング数式。

---

## コスト構成

### 月額運用コスト（日次 1,000 ファイル変更時）

| コンポーネント | 価格基準 | 月額コスト |
|-------------|---------|-----------|
| AWS Lambda | $0.20/100万呼び出し + コンピュート | ~$6 |
| Amazon Bedrock (Claude) | トークン単位（下表参照） | ~$65 |
| Amazon Titan Embeddings | $0.0001/1K トークン | ~$1 |
| S3 Tables (Iceberg メタデータ) | $0.01/GB/月 | ~$0.05 |
| OpenSearch Serverless | $0.24/OCU/時間（スケールトゥゼロ対応） | ~$42 |
| **合計** | | **~$114/月** |

### ファイルサイズ別 Bedrock コスト

Bedrock 分類コストはファイルサイズにより大きく変動します：

| ファイルサイズ | ファイルあたり概算コスト | 典型的なコンテンツ |
|-------------|:--------------------:|-----------------|
| 1 KB テキスト | ~$0.01 | 短いテキストファイル、設定ファイル |
| 100 KB ドキュメント | ~$0.05 | 標準的なビジネス文書 |
| 1 MB PDF | ~$0.07 | 複数ページのレポート、契約書 |
| 10 MB 画像 | ~$0.15 | 高解像度画像、スキャン PDF |

**注意:** 実際のコストはプロンプトの複雑さ、出力トークン数、ビジョン（画像）処理かテキストのみかにより変動します。$0.07/ファイルの見積もりは 100KB–1MB 文書の混合を想定しています。

### アイドルコスト

ファイル処理が行われていない時：
- Lambda: $0
- Bedrock: $0
- S3 Tables: ~$0.05/月（メタデータストレージのみ）
- OpenSearch Serverless: ~$5/月（スケールトゥゼロの最小値）

**アイドル合計: ~$5/月**

## コスト比較: メタデータのみ vs フルコピー

| アプローチ | 月額ストレージ | データ移動 | 月額合計 |
|----------|:-----------:|:--------:|:-------:|
| **本ソリューション（メタデータのみ）** | $0.05 (5 GB) | $0（ゼロコピー） | **$114** |
| S3 Standard（100 TB フルコピー） | $2,300 | $90/月（同期） | **$2,390** |
| S3 + Glue Crawler | $2,300 + $44 | $90/月（同期） | **$2,434** |

**注意:** ストレージコスト比較は、代替案が全データの S3 コピーである場合のみ有効です。NAS データを全て S3 に複製する計画がない場合、この比較は理論上のものです。

## 数式リファレンス

```
月額パイプラインコスト =
  (日次変更数 × 30 × ファイルあたりコスト)     # Bedrock 分類（ファイルサイズ表参照）
  + (日次変更数 × 30 × $0.001)                 # Titan 埋め込み
  + (日次変更数 × 30 × $0.0002)                # Lambda
  + (メタデータ_GB × $0.01)                     # S3 Tables
  + (opensearch_ocu_時間 × $0.24)               # OpenSearch
```

## 前提条件と注意事項

| 前提条件 | 現実チェック |
|---------|------------|
| ファイルサイズ平均 100KB–1MB | 大きなファイル（画像・動画）は Bedrock コストを大幅に増加させる |
| デフォルトプロンプトで分類 | カスタムプロンプトで出力トークンが多い場合、ファイルあたりコスト増加 |
| OpenSearch スケールトゥゼロ使用 | 最小 OCU 割り当てが適用（アイドル時でも ~$5/月） |
| S3 Tables 価格が安定 | S3 Tables GA 2024年12月; 価格変動の可能性あり |
| 単一リージョンデプロイ | マルチリージョンは SnapMirror + パイプライン重複コスト追加 |
| 標準並行性 | 高並行性は Lambda 予約済み同時実行数（追加コスト）が必要な場合あり |
